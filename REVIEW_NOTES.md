# DECIMAG website review build

## What changed

- Kept the current site's dark, cinematic storytelling direction and static GitHub Pages architecture.
- Reframed the homepage around DECIMAG and the execution gap rather than a wall of cybersecurity incidents.
- Added Product, Technology, Enterprise, Research and Explore pages.
- Added the approved conceptual architecture, with Organizational Reality feeding Structural Evaluation.
- Added clearly separated Command Core, Runtime Console and Decision Relay product-demonstration views.
- Embedded the existing DECIMAG film and retained the existing console demo, interactive demo and arXiv links.
- Replaced the old Ask DECIMAG content with a focused FAQ while retaining `ask.html` as a compatibility redirect.
- Changed the primary CTA to Request a Demo, with Talk to DECIMAG as the alternative.

## Boundaries preserved

- Decision Relay is described only as transporting an already-made decision.
- Console examples are labeled as fixture data, not a live deployment.
- Structure Acquisition is described at the architectural level; proprietary implementation is not exposed.
- No customer deployments, benchmarks, certifications or partnerships are claimed.
- No Runtime API, authentication, delivery service or backend behavior was added.

## Review status

This package is for content, product-accuracy, visual, mobile, link, console and film review. It has not been deployed and makes no DNS changes.
